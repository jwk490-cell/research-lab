비교 기준·데이터 범위

마지막으로 직접 저장한 기준과 현재 발행 데이터를 비교합니다. ‘이 종목 전체 확인 완료’는 선택한 유형 외의 항목도 함께 갱신합니다. 읽기 실패한 데이터의 기존 기준은 보존합니다.

관심종목과 기준은 현재 브라우저·사이트 주소에만 저장됩니다. 화면을 열거나 새로 읽기를 누르면 데이터를 갱신하며, 닫힌 화면에서 알림을 보내지는 않습니다.

수급 목록 이탈은 순매도 전환을 뜻하지 않습니다. OP 컨센은 저장 시점 대비 비교이며, 서로 다른 추정연도를 섞지 않습니다. 결측·실패를 하락으로 간주하지 않습니다. 가동률은 보고기간 평균입니다.
